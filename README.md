# 群消息收集工作流 Skill

公开通用版1.1。适用于报账、业绩/报名上报、资料收集系统的设计、审查、项目复制、验收与执行端交接。

本仓库提供AI技能说明，不是已经部署的机器人、会计系统或运行程序。没有实际组织名称、账户/文档标识、密钥、客户资料或真实台账；示例金额均为模拟测试输入。

## 包含内容

`skills/group-collection-workflow/` 包含主技能、报账/业绩/资料三个模块、交付测试说明以及Codex界面元信息。按场景加载，不必每次读所有模块。

## 使用方法

在支持SKILL.md的工具中，安装或导入整个 `group-collection-workflow` 文件夹，保留references目录。Codex个人技能目录可使用 `~/.codex/skills/`；其他工具请按其支持的导入方式操作，不能假定安装路径相同。

调用示例：

> 用 $group-collection-workflow 为我的项目设计群内报账流程。先生成规则、配置需求和测试方案，不写正式账、不发群消息。

> 用 $group-collection-workflow 审查销售业绩上报流程，区分签单额、实收和退款，保留原有审批制度。

> 用 $group-collection-workflow 设计资料收集流程，支持部分接收与版本替换，敏感资料不回显到群。

需要自行提供项目规则、群/文档标识、成员映射、默认值与查看权限；这些实际配置不应提交到公开仓库。技能不会自动绑定账号、安装执行器、保证并发安全或替代平台权限。
