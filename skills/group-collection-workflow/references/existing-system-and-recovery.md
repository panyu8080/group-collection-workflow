# 已有系统接手、断线与离线恢复

用于接手已有流程、复制新业务、排查不响应，以及非全天开机的收集系统。这里只提供方法，不证明某平台可读取历史，也不自带重连或扫描程序。

## 接手：先找证据，不先重建

1. 从用户给的项目、配置、交接和必要日志位置做小范围只读查找；敏感配置不打印秘密。找不到先报告搜索范围，不把“本目录未找到”写成“全机不存在”。范围外查找明显费时或涉及无关隐私时先说明。
2. 分清平台连接器、消息投递会话、执行工具、业务程序、目标表与回执入口。服务可能由执行产品或远端提供，本地项目缺少接收服务代码不足以证明没有执行链。
3. 用简表列“证据／对象与时间版本／能证明什么／仍缺什么”。文档写有能力不等于历史跑通；历史跑通不等于当前在线；当前单聊成功不等于群、写表、业务核心全通过。
4. 优先复用工具调用方法和获准保留的连接；复制新业务时，群、表、角色、默认值和业务制度独立配置。若继续使用原项目，保留其已核实路由，不为了独立配置擅自换ID或表。
5. 只做当前任务必要的分层检查。已有证据能复用的，不要求用户凭记忆重新描述全部流程；缺API只标能力缺口，不推定账号没有权限。不因掉线就重绑、新建机器人、重置凭据或部署新服务。

需要发消息或写表测试时，先明确已授权的测试账号、群、表和动作。只读接手不自动授权测试或上线。

## 不响应：定位哪一段失败

依证据区分执行端未启动、网络／连接中断、成员准入或可见范围、消息入站失败、会话路由错误、模型限流、工具调用失败、文档授权过期、具体文件权限、写后结果和出站回执。

- 单聊可用但群不可用：检查群消息投递、普通成员身份和群支持条件，不把单聊结果推广到群。
- 群能回复但没写表：检查目标文档、授权和业务调用，不先认定模型不够聪明。
- 当前接口超时：先核远端任务结果，避免重连后重复写。
- 429、额度不足不是同一种断线；退避和恢复条件据实际返回处理，保留任务状态，不忙循环、不擅自换付费模型。

修复后分别验证消息接收、正确会话与业务调用、目标行写入读回、原通道回执。只验证了部分就报告部分，恢复连接不等于离线账目全部处理。

## 非全天开机：两种可选触发

由用户选择并写入配置，可单独启用或同时启用：

- 启动／恢复触发：执行端确实启动且连接可用后，从可信检查点增量补读。电脑开机本身不证明程序运行；自启动、重连检测和历史读取分别验收。
- 负责人指令：例如“检查遗漏”“补读某群某日期范围”“继续补读”。短语只是指令，不是密码；只接受已核验身份在获准入口发出的操作。

只扫描获准绑定的群或会话。首次无检查点时确定起始范围，不自动导入全部历史。自动重复触发应合并，手动、自动、实时入口共用防重与写入互斥；不为每次网络抖动重扫全历史。

## 检查点与业务进度分开

- 扫描任务保存群、时区、起止范围、分页游标、实际覆盖、异常及恢复位置。自然日范围为起始日00:00至结束日次日00:00，左闭右开。
- 业务任务另存草稿版本、确认快照、写入操作键及处理状态。扫描过不代表已确认、已写入、已审批或已付款。
- 增量补读可用经验证的重叠区间防漏边界，长度按平台配置；未完成分页不能把覆盖点提前推进到当前时间。游标失效按源键核对后重放，不猜进度。
- 原始消息／附件可取得范围、排序与分页稳定性逐项验证。窗口过期、撤回、附件不可取时报告缺口，提供人工转发、导出或文字补充方案；不保证固定天数，不绕过官方访问限制。

## “未处理”不是一种状态

| 情形 | 允许的后续处理 |
|---|---|
| 新消息尚未抽取 | 按场景生成草稿或登记收到的资料；需确认的不得直接生效 |
| 已有草稿待确认／待补 | 继续同一任务，不重复造草稿；提醒按已批准策略，不每扫一次催一次 |
| 可靠确认已保存、写入中断 | 先核远端操作键与结果，再补未完成步骤；没有快照不能跨重启猜确认 |
| 已提交待审批／已批准待付款 | 列业务待办，不当成漏账重写，不代替审批或虚构付款 |
| 已完成 | 跳过重复写，必要时返回原记录；不无故重复发送群回执 |
| 覆盖不完整／附件未核验 | 标出范围和原因；不能把“可取得内容中未发现遗漏”说成“全部历史无遗漏” |

补读报告只向授权入口说明覆盖、新记录、续做、待办和缺口，避免跨群合计泄露敏感数据。恢复请求不自动授权补发真实群消息、改审批、付款或删除记录；沿用用户明确的执行范围。

## 省成本与验收

正常单笔只必要路由／字段／版本／防重检查和涉及行读回。结构与汇总检查按启动、版本变更或批准计划执行；备份按批准批次／频率，不因内部拆块反复全备份。保留关键保护，不为加速关闭防重或核验。

优先测试恢复半途重启、自动与手动并发、实时与补读重叠、历史不可取、附件缺失和同额不同消息。先本地模拟，获准后再验证平台及手机；二者分别记录，不以提示词或技能安装代替功能验收。
